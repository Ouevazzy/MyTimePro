# Documentation Apple récupérée — 17 septembre 2026

33 documents officiels enregistrés, dont les notes complètes iOS/iPadOS 27 et Xcode 27. Les guides de frameworks peuvent aussi décrire des API antérieures à iOS 27.

Ce corpus est ciblé sur WorkTimer ; il ne constitue pas une copie exhaustive de toutes les API, vidéos et exemples Apple. Les liens des index permettent de poursuivre la consultation. Aucun SDK supplémentaire téléchargé : le SDK complet iOS 27.0 est déjà installé avec Xcode 27.0.

Chaque téléchargement est tracé dans [manifest.json](manifest.json), avec URL, date, taille et empreinte SHA-256. Les fichiers `.json` des Human Interface Guidelines sont les sources Apple ; les `.txt` voisins sont des extractions de lecture simplifiées, les sources JSON restent la référence.
